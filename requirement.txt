1. Use Terraform Device

If there are 1 or more, ask the user if they would like to use one in the current sector to create a planet. 
If they say yes, then choose a random planet type and create a planet of that type in the sector.

then a new record should be inserted in the planet_collisions table. Pick one of the other planets in the sector at random to be one of the planets in the collision.

2. Land on Planet
This command is partly implemented. When the user uses the L key from the sector menu, the game should list available planets by id, name, and type.
The player must type a planet id (also let them quit back to sector menu) to land. Once landed, they are on the planet menu. 
Available commands here are Q (to leave the planet and go back to the sector menu), D (to display the planet; show all values stored on the planets table),
and Z to destroy the planet. If the user destroys the planet, they are returned to the sector menu. The planet should be deleted, and the planet_collisions entry,
if any, should be deleted (via cascading delete - add the constraint if it does not exist). Show appropriate messaging to the player.
